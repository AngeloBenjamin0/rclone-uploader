Privacy policy

Last updated: November 7, 2026. Applies to "Angelo's rclone uploader" (the app), a personal tool run on the developer's own computer.

Data the app accesses

When a user signs in, Google issues the app an access token for the drive.file scope. With it the app can create, read, change and delete only the files and folders that the app itself created in that user's Google Drive. It cannot see any other file. The app does not request the user's contacts, email or profile data beyond what Google's sign-in flow requires.

How the data is used

The app uses that access only to upload files the user chooses to a Drive folder, and to check that the upload is complete. It does nothing else with the files.

Storage and sharing

  • The sign-in token is stored only on the user's computer, in the rclone configuration file.
  • The app has no server and no database. The developer does not receive, collect or store users' files or tokens.
  • No data is sold, shared with third parties, used for advertising, or used to train AI models.
  • No analytics or tracking is used on this website.

Google API Services user data policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

A user can revoke the app's access at any time at myaccount.google.com/permissions, and can delete the stored token by removing the remote from their rclone configuration. Files the app uploaded stay in the user's Drive until the user deletes them.

Changes

If this policy changes, the new version is published at this address with an updated date.
